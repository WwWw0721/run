03 — GO BACK

跑完之後，怎麼回飯店？

兩種大眾運輸都能用。想走熟悉的路選「捷運紅線原路返回」；想從時代大道附近直接搭車，可選「輕軌到 C7」。

推薦 · 跟去程相反方向

方案 A｜搭紅線回 R8

時代大道 → R6 凱旋 → R8 三多商圈 → 飯店

  1. 從時代大道走到 R6 凱旋站。 可反向使用去程導航。
  2. 搭「往岡山車站」方向。 R6 → R7 獅甲 → R8 三多商圈；2 站，不轉車。
  3. R8 下車後步行回飯店。 約 700 公尺、9～12 分鐘。
會場 → R6 導航 ↗R8 → 飯店導航 ↗
另一種選擇 · C5 站靠近時代大道

方案 B｜搭輕軌到 C7

時代大道 → C5 夢時代 → C7 軟體園區 → 飯店

  1. 步行到 C5 夢時代站。 車站在成功二路與時代大道路口。
  2. 搭「順行」方向。 C5 → C6 經貿園區 → C7 軟體園區；2 站。
  3. 從 C7 步行回飯店。 請用導航確認距離與人行道動線。
會場 → C5 導航 ↗C7 → 飯店導航 ↗
提醒：輕軌「順行」與「逆行」是繞環狀路線的不同方向。從 C5 到 C7，應搭 順行（下一站 C6 經貿園區）。千萬不要只看列車終點，方向選錯可能會繞很大一圈。

FAQ

容易搞混的地方

去程和回程搭車方向一樣嗎？

不一樣！去程 R8 → R6 要「往小港」；回程 R6 → R8 要「往岡山車站」。

如果路跑結束想直接在夢時代附近搭車？

可以選回程方案 B：步行到 C5 夢時代站，搭輕軌「順行」到 C7 軟體園區，再照地圖走回飯店。

網頁會自動顯示即時列車嗎？

不會。表格是已核對的官方假日表定時刻；要看即時到站，點右側的「高捷即時到站資訊」。

活動完要怎麼把公開網站關掉？

到 GitHub 儲存庫 Settings → Pages，取消發佈（Unpublish site），即可讓網站下架。請保留網站管理權限。
